# 🧩 AI 파츠 분리기

이미지를 올리면 AI가 사물별로 잘라 **배경이 투명한 PNG 파츠**로 만들어 주는 웹앱입니다.
모든 AI 처리는 브라우저 안에서 이루어지며(Transformers.js), 이미지는 어떤 서버로도 전송되지 않습니다.

## 기능
- **⚡ 자동 분리**: DETR 파놉틱 모델이 이미지 속 사물(사람, 동물, 물건, 배경 영역 등)을 찾아 파츠로 나눕니다.
- **👆 클릭으로 분리**: SlimSAM 모델로 원하는 부분을 직접 고릅니다.
  - 왼쪽 클릭 = 포함할 부분, 오른쪽 클릭(또는 Shift+클릭) = 제외할 부분
  - 마음에 들면 “파츠로 추가”
- 파츠마다 PNG 저장, 이름 변경, 삭제
- **ZIP 저장**: 모든 파츠 PNG + 원본 이미지에서의 위치가 담긴 `layout.json`
- 드래그 앤 드롭, 파일 선택, 클립보드 붙여넣기(Ctrl+V) 지원

## 실행 방법
빌드가 필요 없는 정적 파일 하나(`index.html`)입니다. 아무 정적 서버로 열면 됩니다.

```bash
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000 열기
```

GitHub Pages에 그대로 올려도 동작합니다 (Settings → Pages → 브랜치 선택).

> 처음 실행할 때 AI 모델을 내려받습니다 (자동 분리 약 170MB, 클릭 분리 약 15MB).
> 한 번 받으면 브라우저 캐시에 저장되어 다음부터는 빠르게 시작합니다.
> 큰 이미지는 긴 변 2048px로 줄여서 처리합니다.
